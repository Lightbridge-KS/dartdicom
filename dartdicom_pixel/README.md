# dartdicom_pixel

Turns DICOM Pixel Data into typed arrays, applies the Modality and VOI LUTs, and produces 8-bit display buffers ready for Flutter or PNG encoding. Pure Dart; runs on every platform.

> **Status: pre-release (`0.1.0-dev.1`).** Not published yet. See the [workspace README](https://github.com/Lightbridge-KS/dartdicom) and the [design docs](https://github.com/Lightbridge-KS/dartdicom/tree/main/docs).

Part of the [dartdicom](https://github.com/Lightbridge-KS/dartdicom) family. Not a medical device; not for diagnostic use.
