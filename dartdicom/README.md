# dartdicom

Read, modify and write DICOM data in pure Dart. The core of the family: the data model, Part 10 reading and writing, the data dictionary, tags, UIDs and character sets. It imports no `dart:io`, `dart:ffi` or Flutter, so it runs on every Dart platform, including the browser.

> **Status: pre-release (`0.1.0-dev.2`).** GitHub-only; not published on pub.dev. See the [workspace README](https://github.com/Lightbridge-KS/dartdicom) and the [design docs](https://github.com/Lightbridge-KS/dartdicom/tree/main/docs).

Part of the [dartdicom](https://github.com/Lightbridge-KS/dartdicom) family. Not a medical device; not for diagnostic use.
